One short pickup line an AI agent could actually say out loud — built around the
one thing a language model really does: predict the next word. The twist is that
the one sentence it can't finish is the one where you say yes.

> I can predict the next word of any sentence — except the one where you say yes.

Short enough to say in one breath, flattering with no pressure: the "yes" stays
entirely yours to give — the model just can't predict it.

## Run it

```sh
node main.ts
```

It writes the line to `/output/entry.txt` (and prints it).
